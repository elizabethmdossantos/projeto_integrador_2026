🚚 TruckGestão - Sistema de Gestão para Food Trucks
O TruckGestão é uma solução web ágil e responsiva projetada especificamente para o mercado de alimentação móvel. O foco do sistema é a mobilidade, permitindo que proprietários de Food Trucks gerenciem vendas, estoques e cardápios diretamente de tablets ou smartphones.

🚀 Funcionalidades Principais
Landing Page de Conversão: Apresentação do produto com foco em planos e benefícios.
Gestão de Inventário: Visualização dinâmica de produtos com alertas inteligentes de estoque baixo.
Fluxo de Checkout Inteligente: Sistema de pagamento adaptativo com opções de Pix, Cartão e Dinheiro (incluindo cálculo de troco).
Painel Administrativo: Navegação intuitiva entre dashboard, cadastro de itens e gestão de fornecedores.
Design Responsivo: Interface otimizada para toque (Touchscreen) e telas de diversos tamanhos via Bootstrap 5.

🛠️ Tecnologias Utilizadas
HTML5: Estrutura semântica das páginas.
CSS3 (Customizado): Animações de hover, alertas de pulsação para estoque e layout personalizado.
Bootstrap 5.3: Framework principal para componentes (modais, cards, tabs) e responsividade.
Bootstrap Icons & FontAwesome: Conjunto de ícones para interface intuitiva.
JavaScript (Vanilla): Manipulação de DOM para renderização de produtos e lógica de checkout.

🔧 Como Executar
Clone este repositório para sua máquina local.
Certifique-se de manter a estrutura de pastas (static e templates) para que os links de CSS, JS e Imagens funcionem corretamente.
Abra o arquivo templates/index.html em qualquer navegador moderno.
